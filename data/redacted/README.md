# Redacted experiment data

This directory is the full, de-identified experiment archive for the map
reconstruction study. It is a companion to the code and paper materials in the
repository root.

## What is included

| Path | Contents |
|---|---|
| `runs/<run_id>/` | One directory per archived attempt: final candidate PNG, 8x PNG, candidate CSV, error map, generated script, last message, and a cleaned `meta.json` |
| `tables/runs.csv` | Flat run-level table (1,073 rows) with scores and per-map metrics |
| `tables/by_channel_task.csv` | Mean metrics by channel and map |
| `tables/status_counts.csv` | Attempt counts by channel and status |
| `summaries/batch-XX_*` | Per-batch summaries generated by the experiment runner |
| `analysis/batch-15/` | Known-shift probe: protocol, report, audits, scorer stress test |
| `analysis/batch-16/` | Negative-correlation / reasoning-budget experiment: protocol, report, tables |
| `analysis/batch-17/` | Independent supplement verification for the 2026-11-05 batch |
| `manifest.json` | Machine-readable index of every run |
| `channels.json` | Channel index (run counts, models, tasks, batch ids) |

Raw request bodies, provider responses, tool transcripts, `_runs/` execution
directories, and API access logs are intentionally excluded. Their contents can
contain endpoints, credentials, client IPs, and routing metadata.

## De-identification

Channels are replaced by stable codenames. `OR` is the baseline channel; `A`–`G`
are the main comparison channels; `S1`/`S2` are the two supplement batches. The
mapping is not published, and the codenames match those used in
`paper_framework/analysis/`.

Every text artifact was passed through a scrubber that removes:

- provider names, aliases, and database ids
- `base_url`, API keys, bearer tokens, and credential names
- client IPs, channel ids, and local absolute paths
- raw HTTP endpoints

Model display names are normalized (for example `GPT 6.1 Sol OR` and
`GPT 6.1 Sol AH` both become `GPT 6.1 Sol`); the `channel` column preserves the
comparison.

## Reproducing the tables

The redacted tables are derived from `runs/*/meta.json`:

```powershell
python - <<'PY'
import csv, json, pathlib
root = pathlib.Path('data/redacted')
rows = [json.loads(p.read_text(encoding='utf-8')) for p in root.glob('runs/*/meta.json')]
print(len(rows))
PY
```

The original builder is `tools/redact_experiments.py` in the parent project. It
reads the private archive and writes this directory; it is not part of the public
data and must not be run against a public checkout.

## Integrity

`checksums.sha256` lists SHA-256 for every file in this directory. Verify with:

```powershell
Get-ChildItem -Recurse -File | ForEach-Object {
  $h = (Get-FileHash $_.FullName -Algorithm SHA256).Hash.ToLower()
  "$h  $($_.FullName.Substring((Get-Location).Path.Length + 1))"
} | Set-Content checksums.sha256
```
