# 低成本行为探针：补充实验执行报告

生成时间：2026-10-29（Asia/Shanghai）

## 1. 结论先行

本轮完成了三项**零新增模型调用**的补充分析，并尝试执行预注册的 H/L/H-sham 已知偏移实验。正式 36 次平衡实验**未完成**：多次更换服务路径后仍遭遇 HTTP 402、HTTP 502、SSL 握手超时、流中断和部分交付；正式归档仅得到 4 个完整运行和 6 个部分运行，**没有形成任何 H–L 配对**。


因此，本轮不能对“探针能检出超过自然波动的已知偏移”作确认性结论。可支持的表述是：

> 既有 5 个 low−high 配对在准确率、HSS、边界 F1 和面积加权分量 IoU 上呈一致的负向线索（4/5 配对下降，未校正精确单侧 p=0.0625；Holm 校正后不显著）；但效应绝对值均未超过同配置历史运行自然差值的 95% 分位，且分量 IoU 中位数与近陆水域指标方向不稳定。该证据足以支持后续预注册实验，尚不足以支持检测器有效性或“降智”结论。

## 2. 完成的分析

### 2.1 903 次既有归档审计

- 主分析尝试：**903** 次；完整可评分 **578** 次，部分交付 **63** 次，失败 **262** 次。
- 另有未进入主分析的 C 批次记录 18 条，继续排除。
- 六个任务的提示哈希在非失败运行中均只有 1 个取值，提示版本一致。
- 准确率与 HSS 的 Pearson 相关为 **0.9951**，不能作为两份独立证据。
- 准确率与边界 F1 的相关为 **0.8820**，与分量 IoU 中位数的相关为 **0.6364**；结构指标提供了部分额外信息，但并非完全独立。
- 成本只能在服务返回 `usage.cost` 时观测；A–F 的订阅/代理路径大多未返回逐次成本，不能把缺失值记为 0。

明细：`existing_audit/REPORT.md`、`existing_audit/attempts.csv`、`existing_audit/metric_pearson.csv`、`existing_audit/lomo_gpt61.csv`。

### 2.2 评分器压力测试

- 六幅参考图，共 **492** 个场景。
- 扰动：边界平移 1–3 格（四方向）、小岛删除（5/20/50 格阈值，25%/50%/100%）、近陆窄水填塞（25%/50%/100%）、虚假陆地块（5/10/20 方形）。
- 8 组预设“应下降”检查全部通过方向检查。
- 但分量 IoU 中位数在小岛删除 25%/50% 时中位变化为 0，说明该指标对稀疏小岛删除可能不敏感；不能把它当作唯一结构证据。
- 结果只支持“评分器对定义扰动有预期响应”，不构成模型能力下降证据。

明细：`scorer_stress/REPORT.md`、`scorer_stress/stress_runs.csv`、`scorer_stress/expected_direction_checks.csv`。

## 3. 正式 H/L/H-sham 实验执行情况

- 设计：6 图 × 3 组 × 2 重复 = 36 次。
- 唯一操纵：`reasoning.effort=high` 对 `low`；H-sham 使用相同 high 配置的独立归档根。
- 正式路径：channel-F / `gpt-6.1-sol` / `api` 后端。
- 正式归档：10 次尝试，ok 4，partial 6；**0 个 H–L 配对**。
- 失败模式：SSL 握手超时、`partial deliverables`、50 分钟超时；部分运行虽可恢复矩阵，但状态仍为 partial，未进入质量分析。
- 其他路径：channel-OR 返回 HTTP 402；channel-C `api-tools` 出现 partial，`api` 返回 HTTP 502；channel-A 订阅路径流中断；channel-F `api-tools` 长时间无响应。

按预注册停止规则，没有重跑或挑选成功运行来制造平衡，也没有对不完整样本作确认性推断。

明细：`PROTOCOL.md`、`analysis/audit.json`、`analysis/arm_balance.csv`、`analysis/run_level.csv`、`logs/`。

## 5. 建议的下一步
